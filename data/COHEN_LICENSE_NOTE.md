Source: https://dmice.ohsu.edu/cohenaa/systematic-drug-class-review-data.html

Gold file used: `epc-ir-data/epc-ir.clean.tsv` (topic, EndNote ID, PMID, Abstract Triage, Article Triage).

**Citation (required):** Cohen AM, Hersh WR, Peterson K, Yen PY. Reducing Workload in Systematic Review Preparation Using Automated Citation Classification. *J Am Med Inform Assoc.* 2006;13(2):206–219. doi:[10.1197/jamia.M1929](https://doi.org/10.1197/jamia.M1929)

This is **custom open data from the authors’ page — not CC-BY**. Do not claim Creative Commons. Always cite Cohen 2006.

This demo uses **Abstract Triage Status only** (`I` = include; else exclude) for the **ADHD** topic (N=851). Title+abstract text is fetched from MEDLINE/PubMed by PMID (same evidence modality as abstract triage). Article Triage is never used as gold.
